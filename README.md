# Sylva

The first published version of Sylva, an EE1111A automatic plant-care product concept.

Live site: https://samsonzh0ng.github.io/sylva/

The static website is in `dist/`. Pushes to `main` deploy it with GitHub Pages.
The repository contains the public website and required assets. Working scenes,
course files, internal documentation and unpublished film studies stay local.

Asset credits: see `dist/assets/plant-realism/CREDITS.txt` and
`dist/assets/fonts/OFL-Manrope.txt`. Third-party library license notices remain
in their distributed source files.
